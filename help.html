🔗 URL
Silence URLs
Master switch under Options → URL Handling. When ticked, all URLs and bare domains — including ones wrapped in [square brackets] like [thestar.com.my] — are stripped from the text before speaking. The three items below it become greyed out because there's nothing left to announce, prefix, or pronounce.

Handles both protocol URLs (http://, https://, www.) and bare domains (rttnews.com, thestar.com.my). Brackets and orphaned whitespace are cleaned up too.
🔗 URL
Announce Source
When ticked, a sentence-final domain like ... data centers [thestar.com.my]. is spoken as ... data centers. Source: thestar.com.my. — a short pause is inserted before the prefix so it doesn't run into the previous sentence.

Only fires on domains that end a sentence (followed by ., !, ?, or the end of the text). A URL on its own — the entire textbox being just a URL — is read plainly with no prefix, because there's no sentence for it to be a source of. Disabled when Silence URLs is ticked.
🔗 URL
Source Prefix…
Opens a small dialog where you choose the word or phrase used by Announce Source. Default is Source:. You can set it to anything — From:, Reported by:, Per:, Quelle:, 来源：, or a custom phrase.

Auto-colon rule: if what you type ends in a letter or number, a colon is added automatically. If you type your own punctuation (a colon, a dash, a full-width colon), it's preserved exactly as typed. An ⓘ icon next to the field shows example usage.

Disabled when Silence URLs is ticked.
🔗 URL
Force English Domain Pronunciation
Rewrites domains so a non-English voice (like Microsoft Vivienne, a French-native multilingual voice) pronounces them the English way:
  • thestar.com.my → thestar dot com dot my
  • rttnews.com → rttnews dot com
  • 192.168.1.1 is left alone — the pattern requires a letter-based TLD
Fixes the "ko'un" sound that French-native voices produce when they read .com naturally. Works on two-segment (.com, .org) and three-segment (.com.my, .co.uk) domains alike. Disabled when Silence URLs is ticked.

📖 Dictionary
Pronunciation Manager
Open it two ways — both use the same editor and the same pronounce.txt file:
  • Options → Pronunciation… in the main window
  • 🔤 Pronunciation… in the tray menu
The tray-launched version is modeless and standalone: it opens as its own window without restoring the main UI, doesn't lock the app, and doesn't float over your other programs. Drag it anywhere, keep your browser or editor visible, and use the tray menu while it's open.

Map any token to whatever you want spoken in its place — for example:
  • Mr. → Mister
  • @ → at
  • SQL → sequel
  • ❤️ → heart
Entries are case-insensitive. Alphanumeric tokens match as whole words; tokens that contain punctuation or emoji match literally. The dictionary is applied after URL handling and context rules, but before the emoji pass. pronounce.txt lives next to the exe and can be hand-edited — the app reloads it on save.
📖 Dictionary
Pronunciation Manager — Search & Sort
Inside the Pronunciation Manager:
  • Search — a live filter box sits above the list. Typing filters on both Token and Spoken as. Empty = show everything. No button to press.
  • Sort — click the Token or Spoken as column header to sort A→Z; click the same header again to flip to Z→A. The active column shows a small ▲ or ▼ next to its title.
  • Filter then sort — search narrows the list first, then the chosen column/direction sorts only the visible rows.
  • Persists while the app runs — sort column, sort direction, and search text survive closing and reopening the manager. A full app restart resets them.
📖 Dictionary
Context Rules for Abbreviations
Before the pronunciation dictionary runs, the app inspects ambiguous abbreviations and picks the right expansion based on the words around them. Examples:
  • St. Louis → Saint Louis, but Main St. → Main Street
  • Dr. Smith → Doctor Smith, but Elm Dr. → Elm Drive
  • no. 5 → number 5, but No. Really? left alone
  • 12 in. long → 12 inches long, but Walk in. left alone
  • Ft. Lauderdale → Fort Lauderdale, but 6 ft. rope → 6 feet rope
  • Col. Smith → Colonel Smith, but see Col. 3 → see column 3
Also covers the unambiguous set: address suffixes (Rd., Ave., Blvd., Cres., Pkwy., Hwy., Ln., Pl., Sq., Terr., Rte., Apt., Ste., Bldg., Rm.), business suffixes (Inc., Ltd., Corp., Co., Bros., Assn., Mfg.), military ranks (Gen., Sgt., Capt., Lt., Cpl., Pvt., Cmdr., Adm.), academic degrees (Ph.D., M.D., B.A., B.S., M.A., M.S., D.D.S., D.V.M.), country abbreviations (U.S., U.S.A., U.K., U.N.), and scholarly markers (e.g., i.e., etc., vs., cf., viz., et al., approx.). Page and section markers (p., pp., Vol., Ch., Sec., Fig., Eq.) expand only when followed by a number.

Context rules run before the user dictionary, so they can't be overridden by a pronounce.txt entry — the app makes the smart call first.
📖 Dictionary
Pronunciation Manager — Emoji Tokens
Emoji tokens like ❤️ are fully supported and searchable. To keep matching predictable:
  • Variation selectors are ignored — the invisible U+FE0E / U+FE0F characters are stripped from both the search query and the entry before comparing. So ❤ and ❤️ are the same token, and searching either finds the other.
  • ZWJ sequences and skin tones must match exactly — sequences like 👨‍👩‍👧 (family, joined by invisible Zero-Width Joiners) and skin-tone variants like 👍🏻 are deliberately kept distinct from their base characters. If you want a rule for 👍🏻, add it as its own entry.
  • Rendering — the list uses Segoe UI Emoji so tokens appear as real glyphs rather than empty boxes. The rest of the manager stays in Segoe UI for readability.
▶️ Controls
Speak
Restarts reading from the top of the text box. The cursor automatically jumps to position 0 so you always begin at the start.
▶️ Controls
Read from Caret (or Selection)
Starts reading from wherever the text cursor is, instead of from the top. Behavior:
  • If text is selected — reads exactly the highlighted text.
  • If nothing is selected — snaps backward to the start of the sentence the caret is sitting in, then reads to the end.
Any stale pause/resume position is discarded when this button is pressed, so a subsequent Pause uses the new start point. If the box is empty or the caret is past the last non-whitespace character, nothing is spoken.
▶️ Controls
Stop
Immediately stops all speech and clears the queue. The "Last spoken" label is updated.
▶️ Controls
Pause / Resume
Toggles pause on the current speech without discarding the queue. If a saved position exists, clicking this button resumes from the last completed sentence.
▶️ Controls
Opacity Slider
Adjust the window transparency in real time, from 30% (very see‑through) to 100% (fully opaque). The value is saved to settings.txt and restored on next launch.
💾 Tools

Exports the current textbox content to a plain text file.
💾 Tools

Saves the spoken version of the text as a real WAV audio file using SAPI.
💾 Tools
Save to *.mp3
Exports the speech as a real MP3 file. Uses Windows Media Foundation (via NAudio) to encode at 128 kbps – no external encoder needed. While encoding, both save buttons are disabled and the active one shows a live "Encoding... 23s" counter. The window stays fully responsive — you can keep reading, pasting, or working in other apps.
💾 Tools

Empties the textbox and clears the speech queue.
💾 Tools

🖥️ Tray
System Tray Menu
Right‑click the tray icon to:
  • Settings – restore the main window
  • Repeat speech – restarts reading from the top of the textbox
  • Pause / Resume – toggle speech pause
  • Stop – halt all speech
  • Clear text – empty the textbox and clear the queue
  • 🔤 Pronunciation… – opens the Pronunciation Manager as a standalone modeless window. The main UI stays hidden, so you can drag the manager around and keep working in other apps while it's open.
  • Disable / Enable Clipboard – same toggle as the Options menu; the label changes to reflect the current state
  • About – restores the window and opens the About dialog
  • Exit – close the app (with a random goodbye)
📋 Feedback
Reading: (current sentence)
A cyan strip just above "Last spoken" shows the sentence currently being read out loud. Updates instantly when SAPI moves on to the next sentence, and returns to "Reading: (idle)" when the queue is empty. Long sentences are truncated at 120 characters with an ellipsis.
📋 Feedback
Last Spoken Label
A yellow strip below the Reading indicator shows the most recent sentence that finished being spoken. Updated on natural completion, stop, or interruption.
📋 Feedback
Session Restore
On exit, the current text is saved to session.txt. On the next launch, after the greeting plays, a prompt appears with three radio-button options — all visible at once, no dropdown to open:
  • Restore Session (default) – loads the text, no speaking
  • Resume Speech – continues reading from the last completed sentence
  • Clear Session – starts fresh with an empty editor
Press Enter or click OK to confirm. Clicking the window's X (or pressing Esc) treats it as the default — Restore Session.
🛡️ Safety
Crash-safe Sanitization
The following characters are automatically rewritten before reaching the speech engine so they can't crash it: & → "and", < → "less than", > → "greater than", double quotes → single quotes, backslashes → spaces, and invisible control characters are stripped.
🛡️ Safety
Decimal Points Read Correctly
A period between two digits is spoken as the word "point" instead of being treated as a sentence break. So 4.9% is read "four point nine percent" with no awkward pause after "four", and version numbers like 2.5 or IP addresses like 192.168.1.1 also read cleanly.
🛡️ Safety
Emoji are Spoken, Not Silenced
Common emoji are automatically converted to spoken words so they never wedge the synthesizer. Examples: 💋 → "kiss", 🔥 → "fire", 👻 → "ghost", ❤️ → "heart", 😀 → "grinning". Emoji not in the dictionary are silently dropped. This prevents the "stuck synthesizer" bug where a single bad emoji silences all subsequent speech until the app is restarted.
🛡️ Safety
Single Instance
Only one copy of Ghost Reader can run at a time. If you double‑click the shortcut while it's already running (even hidden in the tray), the existing window pops to the front instead of launching a second copy.
🛡️ Safety
Safe Exit During Encoding
If you try to close the app while an MP3 or WAV export is running, a dialog offers to Wait for it to finish or Close anyway and abandon the export. No lost work by accident.
🌏 Language
Chinese Punctuation Support
The app correctly splits text on Chinese punctuation 。！？ so long Chinese texts are read sentence by sentence.
🌏 Language
Multilingual Voices
Works with Microsoft's multilingual neural voices (like Microsoft Vivienne Multilingual Online). These voices auto-detect language and can slip into their native accent on short or ambiguous tokens — particularly bare domains. If a French-native voice mangles .com, turn on Force English Domain Pronunciation under URL Handling to correct just the domain parts while leaving the rest of the voice's accent intact.

🔧 Hidden
The pronounce.txt File
The Pronunciation Manager writes its dictionary here, next to the exe. Format is token=spoken form, one entry per line. Lines starting with # are ignored, so you can add your own comments. It's safe to hand-edit — the app watches the file and reloads it automatically when it changes. Case-insensitive on load.

The file ships prefilled with a starter set of common English abbreviations — Latin scholarly markers, business suffixes, military ranks, medical initialisms, technology acronyms, internet slang, and calendar month abbreviations. Emoji tokens are deliberately not included in the default: emoji are already spoken by the hard-coded emoji pass, and adding them to the dictionary would just duplicate the work. If you want a specific emoji spoken differently from the built-in list, add it via the manager.
🔧 Hidden
The tlds.txt File
A plain-text list of known top-level domains (com, org, my, uk, and so on), one per line, sitting next to the exe. The app uses it to recognise what counts as a domain when applying URL Handling. If the file is missing, a small built-in list is used instead. You can replace it with the full IANA list at any time by saving tlds-alpha-by-domain.txt from data.iana.org as tlds.txt.
🔧 Hidden
Last Spoken Log
Every spoken sentence is appended to lastspoken.log – useful for debugging and tracking interruptions.
🔧 Hidden
Logs Folder
The Logs\ folder holds rotated crash logs (log1.log … log9.log), memory monitoring output (memory.log), single-instance events (single_instance.log), and unhandled/thread exception logs. If anything ever misbehaves, this is where to look.
🔧 Hidden
Borders Settings File
The borders.txt file next to the exe controls the exact pixel positions of every control on the form. Edit it to fine‑tune the layout, then restart.

The file carries a ; layout-version=2 marker in its header. If the file is missing, it is regenerated from the built‑in defaults. If it exists but was written by an older version of the app, it is backed up to borders.txt.v1.bak and regenerated automatically — so future layout changes never clash with an old file. Use Restore Default Borders to regenerate it fresh at any time.
🔧 Hidden
Settings File
The settings.txt file next to the exe stores every preference — voice, speed, volume, opacity, autostart, greeting toggles, and all four URL Handling settings (SilenceURLs, AnnounceSource, SourcePrefix, ForceEnglishDomains). Old versions of the app wrote a SkipURLs key; on first load it is migrated to SilenceURLs and never written again.

💋 About Ghost Reader

Ghost! Clipboard Reader was born in October 2008, the brainchild of a developer named Adaeria – a quiet genius who knew exactly how to make words come alive. Her creation was lean, hungry, and utterly devoted to one thing: taking whatever you gave it and whispering it back to you with feeling.
