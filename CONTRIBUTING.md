# Contributing to GhostBundle

Hey — thanks for wanting to help! GhostBundle is a solo project, so a few notes before you dive in.

## 🐛 Found a bug?

Please [open an issue](../../issues) using the **Bug report** template. Include steps to reproduce it and your Windows version. Screenshots help a lot.

## 💡 Got an idea?

Post it in the [Ideas category](../../discussions/categories/ideas) of Discussions. I read everything, even if I can't reply to everything.

## ❓ Have a question?

Head to [Q&A](../../discussions/categories/q-a) in Discussions.

## 🛠️ Want to contribute code?

Since this is a solo project with a specific style and scope, please **open a Discussion first** before writing code. That way we can agree on the approach before you spend time on it. Unsolicited pull requests for features may be politely declined.

## 📜 Licensing

By contributing, you agree that your contributions will be licensed under the same license as the project (MIT).

Thanks for being here. 🖤
