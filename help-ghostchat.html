System requirements
This app requires 64-bit Windows (x64 or ARM64). It will not run on 32-bit Windows.
Why: the local LLM engine (LLamaSharp) only ships 64-bit native libraries. A 32-bit process cannot load them, and even if it could, a 32-bit process is limited to ~2 GB of memory — far too little to hold a language model.
The exe is named GhostChat64.exe as a reminder. If you try to run it on 32-bit Windows, it shows a short message and exits cleanly instead of failing midway through model load.
🚀 Start
First-time Setup
On the very first launch, the app has no model to load. Here's the two-step setup:
  1. Download a .gguf language model file (see Where to get a model below).
  2. Drop it into the model folder next to GhostChat64.exe — or use Settings → Model → Open model folder to jump there.
Restart the app. It scans the folder, finds your model, and asks you to pick one. Tick Set as default and it will auto-load next time.

Where to get a model
Any .gguf file from these public sources will work:
Hugging Face
huggingface.co/models?library=gguf
The largest collection. Filter by library: gguf and search for a model size that fits your RAM.
TheBloke (archived, still useful)
huggingface.co/TheBloke
Thousands of pre-quantised models. Even though TheBloke stopped publishing in 2023, the archive is a goldmine for older families.
bartowski
huggingface.co/bartowski
The current go-to for fresh quantisations of new releases.
LM Studio's model browser
lmstudio.ai
GUI browser. Downloads land in LM Studio's own folder — copy the .gguf across to ours.
Ollama library
ollama.com/library
Ollama stores models in its own format. Not directly usable — but the "gguf" tags on Hugging Face match.

Which file types work
The app only loads GGUF files. Nothing else.
ExtensionWorks?Notes
.gguf ✅ Yes The only format the app reads. Can be a single file or split into -00001-of-00003.gguf parts — the app picks the first part automatically.
.ggml ❌ No Legacy format. Superseded by GGUF around 2023. If you have an old .ggml, convert it or find the GGUF equivalent.
.safetensors ❌ No Original Hugging Face weight format. Needs conversion to GGUF before this app can use it.
.bin / .pt / .pth ❌ No PyTorch checkpoints. Also need conversion.
.onnx ❌ No A different runtime entirely.
Ollama blobs ❌ No Ollama stores files with hash names inside ~/.ollama/models/blobs. Not readable by this app.
Quick test: if the filename ends in .gguf, it will work. If it ends in anything else, it won't.

Choosing a model size
GGUF models come in "quantisations" — different compression levels of the same model. Bigger files are smarter but slower and need more RAM. Rule of thumb:
QuantSize vs originalQualityRAM needed
Q4_K_M~30%ExcellentFile size + ~2 GB
Q5_K_M~35%Near-losslessFile size + ~2 GB
Q6_K~42%Almost losslessFile size + ~2 GB
Q8_0~55%Effectively losslessFile size + ~2 GB
Starting recommendation: a 7B–14B parameter model at Q4_K_M. Fits comfortably in 8–16 GB of RAM and runs at a usable speed on CPU.

Sending messages
Type in the box at the bottom and either click Send or press Ctrl+Enter. Plain Enter inserts a new line so you can write multi-line prompts.
💬 Chat
Stop generation
Click Stop or press Esc while the model is writing. The reply ends gracefully — the partial text is kept.
💬 Chat
Regenerate
Removes the last reply and asks the model to answer the same prompt again. Useful when sampling produces a reply you don't like — different sample, different answer.
💬 Chat
Delete Last
Removes the last user+assistant exchange from history. Use this before Regenerate when you want a completely clean slate.
💬 Chat
Show thinking
Some models (like Ministral 3 Nymphaea) wrap their reasoning in <think>...</think> tags before writing the visible reply. When this is ticked, both the reasoning and the tags are shown. When off, the whole thinking block is hidden.

Toggle it from the checkbox below the input box, or from Settings → Behaviour → Show thinking. The choice is saved and restored on next launch.
💬 Chat
Auto-copy replies
When ticked, every finished reply is automatically placed on the clipboard. Handy when you want to paste the response straight into another app.
🎛️ Sampling
Sampling Preset
Controls how the model picks the next word. Three presets under Settings → Behaviour → Sampling Preset:
PresetTemperatureFeel
Precise0.3Factual, low variance, safe. Good for questions.
Balanced0.75Default. Good mix of accuracy and liveliness.
Creative1.0High variance, more inventive. Good for stories and roleplay.
Model behaviour varies: a roleplay-tuned model at Creative will be wildly imaginative. A strict instruct model at Creative may hallucinate. If a model behaves strangely, try lowering the temperature before assuming something is broken.
🎛️ Sampling
Generation Limits
Under Settings → Model → Generation limits… you can tune three numbers:
  • Context size — total token budget for the whole prompt (system prompt + history + reply). Default 8192.
  • Reply reserve — the maximum number of tokens the reply can occupy. Default 2048.
  • Safety buffer — headroom so the prompt never overflows the context. Default 512.
The app trims the oldest exchanges whenever the history pushes past context − reply − buffer.
Important: raising the context above a model's training length hurts, not helps. Ministral 3 was trained at 8192; setting it to 12288 makes the model produce shorter, less coherent replies. If your model behaves oddly, put ContextSize back to 8192 first.
Changes take effect on the next model reload.
🧠 Models
Select Model
Under Settings → Model → Select model… you get a list of every .gguf in the model folder. Pick one to load it. Tick Set as default and it will auto-load next time the app starts.
🧠 Models
Reload current model
Re-reads the currently active model from disk. Use this after changing Generation Limits, or after replacing the file on disk with a newer version.
🧠 Models
Prompt Format
Different model families expect different prompt wrappers. The app auto-detects the format by reading metadata inside the GGUF and falls back to filename hints. When it can't tell, it defaults to Mistral.

If a model misbehaves — short replies, echoing the system prompt back, weird role labels — override the format via Settings → Model → Prompt Format:
  • Mistral — [INST]...[/INST] wrapping. Used by Ministral, Mixtral, Mistral Instruct.
  • Llama 3 — <|start_header_id|> headers. Used by Llama 3.x.
  • ChatML — <|im_start|> tags. Used by Qwen, Phi-3, DeepSeek.
  • Gemma — <start_of_turn>. Used by Gemma 2.
  • Alpaca — ### Instruction: style. Older fine-tunes.
Your choice is remembered per model. Reload the model to apply.
🧠 Models
Open model folder
Opens model\ in Explorer. Use this to drop in new .gguf files, or to see what the app has detected.
⚙️ Settings
Identity — Set AI name / Set your name
Changes the labels shown in the chat log. Purely cosmetic — the model doesn't see these names unless you put them in the system prompt.
⚙️ Settings
Edit System Prompt
The persistent instruction sent to the model at the start of every conversation. Keep it short and factual — long-winded system prompts eat context fast and can confuse smaller models.
Tip: explicitly forbid the model from writing User: / System: lines in its output. This reduces role-label leakage that some models fall into.
⚙️ Settings
Layout — Minimum widths
The chat area and image area are separated by a draggable bar. Under Settings → Layout you set the minimum width each side can be dragged to — this stops the splitter from compressing the Send button or squeezing the image out of view.
⚙️ Settings
Save / Open Session
Under File. Save writes the current conversation to a .json file. Open restores it. Sessions include every user/assistant exchange but not the model itself — reload the same model after opening a session to keep replies consistent.
⚙️ Settings
New Session
Clears the conversation and starts fresh. The model stays loaded — only the history is wiped.
🖼️ Images
Image rotation
The right panel cycles through any images placed in images\. It scans subfolders too, and skips hidden/system files. Supported: .png, .jpg, .jpeg, .bmp, .gif.

Toggle rotation on/off under Settings → Image Display. Set the interval (1–600 seconds) there too.
🖼️ Images
Choose static image
Pick a single image to display without rotation. Opens a picker list of every image found. Selecting one automatically turns rotation off.
🖼️ Images
Supported image formats
The image panel only reads formats Windows can decode natively: .png, .jpg, .jpeg, .bmp, .gif.
Not supported: .webp, .avif, .heic. These need a third-party decoder that isn't bundled. Convert them to .png or .jpg first.

To restore the app to a fresh-install state, close it and delete these files next to the exe:
  • settings.txt
  • system_prompt.txt
  • model_settings.json
The app recreates them with defaults on next launch. Your models and images are untouched.
🩺 Fix
Model gives short replies
Usual suspects, in order:
  1. Context size too high. If the model was trained at 8192, running at 12288 makes replies choppy. Set ContextSize=8192 in Generation Limits.
  2. Wrong prompt format. If the reply echoes the system prompt back, the format is wrong. Override under Settings → Model → Prompt Format and reload.
  3. Sampling too conservative. Try Creative. Higher temperature = longer outputs for most models.
  4. Model is just terse. Some instruct models are trained to give one-paragraph answers no matter what. Try a different model.
🩺 Fix
Reply is gibberish, empty, or repeating
Almost always a prompt-format mismatch. Open the debug line in the chat log (it says [Debug]: Gen: N tok ... tail: ...) and look at the tail. If the tail shows the model writing role labels like User: or special tokens like <|im_end|>, it means the model wasn't wrapped in its expected format.

Fix: Settings → Model → Prompt Format → pick the family matching the model (see the Prompt Format entry above) → Reload current model.
🩺 Fix
First token takes a long time
Normal. The model re-reads the entire prompt (system prompt + all history + your new message) before it writes the first token. As the conversation grows, this first-token latency grows too. Once tokens start flowing, the speed is steady.
Speed up: start a new session occasionally to trim history, or use a smaller model, or use a lower quantisation (Q4_K_M is faster than Q8_0).
🩺 Fix
Model fails to load
Usually not enough RAM. A 14B Q4_K_M model needs ~12 GB free. Try:
  • A smaller model (7B instead of 14B).
  • A lower quantisation (Q4_K_M instead of Q6_K).
  • Lower Context size to 4096 — context memory scales with size.
  • Close other memory-hungry apps.

ℹ️ Info
About
Ghost Chat is a completely offline local-LLM chat app. Nothing is sent anywhere. Every reply is generated on your own machine by the .gguf model you loaded. No account, no telemetry, no cloud.

Built with .NET 8 WinForms + LLamaSharp, running the llama.cpp backend on CPU. Model files are not distributed with the app — the user supplies them.

Reachable from Help → About. The dialog shows the version, a link to the Ghost Bundle website, and a voluntary donation button.

💬 About Ghost Chat

A no-nonsense, offline front-end for GGUF language models. Drop a model file in, chat, done. No accounts, no cloud, no telemetry — everything happens on your machine. If a model misbehaves, the fix is almost always a prompt-format override or a context-size adjustment, both of which are one click away in the Settings menu. Made for people who want to run their own models without a launcher, a subscription, or a company watching over their shoulder. Ghost Chat is free, and it always will be.
