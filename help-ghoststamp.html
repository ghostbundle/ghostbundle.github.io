🔴 GhostStamp PRO

Document stamping utility – search below to find what you need
🔍
📂 Loading
Load Document
Click 📂 Load Document (Image/PDF) to open a file. Supports .png, .jpg, .jpeg, .bmp, and .pdf. PDFs are rendered at 200 DPI for crisp text.
📂 Loading
PDF — First Page Only
Only page 1 of a PDF is loaded into the workspace. If the file has more pages, a note appears in the status bar telling you the total page count, but pages 2 and beyond are not currently accessible in the editor.
📂 Loading
Auto-Fit on Load
When a document loads, the app automatically scales it to fit the canvas and centers it. If the document is smaller than the canvas, it stays at 100% (no upscaling — never blurry).
🔖 Seals
Selecting a Seal
Click any seal in the list to equip it. The cursor becomes a crosshair and a ghost preview follows your mouse over the document so you can see exactly where the stamp will land.
🔖 Seals
Pointer Mode
Click 🖱️ Select / Pointer Mode to deselect the current seal and return the cursor to normal. Safe for scrolling, panning, and inspecting the document without accidentally stamping.
🔖 Seals
Reviewer Name Field
Type your initials or name (default MGR). It's substituted into any seal whose template contains {NAME} — currently only REVIEWED, which renders as "BY: MGR DATE: 11-09-2026".
🔖 Seals
Process Date
Choose a date from the picker (defaults to today). Formatted as dd-MM-yyyy and printed under every non-arrow seal's main label. The arrow seals SIGN HERE → and SIGN HERE ← skip the date line by design.
🔖 Seals
Seal Size
A percentage field from 10% to 250%. At 10% a seal is a tiny thumbprint; at 250% it covers a good portion of an A4 page. The chosen scale is applied when you stamp, so you can place several different sizes in one document.

📋 Catalog
APPROVED ✔
The APPROVED seal renders with a checkmark glyph appended, and uses a double-border Badge shape (inner + outer rectangle) to stand out as the "final" seal in a workflow.
📋 Catalog
SIGN HERE Arrows
Two directional arrow seals: SIGN HERE → and SIGN HERE ←. The arrow polygon itself conveys the direction, so no date or name is printed. Use them to flag exactly where a signature is required.
📍 Stamping
Placing a Stamp
With a seal selected, click anywhere on the document to place it. The stamp is stored in image coordinates, so it stays glued to the same document position regardless of zoom level.
📍 Stamping
Ghost Preview
While a seal is selected, a semi-transparent copy follows your cursor across the document. What you see is exactly what will be stamped — same position, same size, same colour.
📍 Stamping
Auto-Return to Pointer Mode
Tick the checkbox to automatically deselect the seal after each stamp. Perfect for workflows where you place one stamp per page — no need to click Pointer Mode between placements.
📍 Stamping
Stamp Counter
The status bar shows a running count of stamps placed ("Stamp placed! (3 total)"), so you always know how many overlays are on the current document.
📍 Stamping
↩️ Undo Last Stamp
Removes the most recent stamp. Click repeatedly to peel back one stamp at a time. There's no redo — once undone, you'd have to place the stamp again.
🔍 View
Zoom — Ctrl + Mouse Wheel
Hold Ctrl and roll the mouse wheel over the canvas to zoom in and out in 5% steps. Range is 15% to 400%. Plain wheel (no Ctrl) scrolls vertically when the document is larger than the viewport.
🔍 View
Auto-Appearing Scrollbars
When the zoomed document is wider or taller than the canvas, scrollbars slide into place automatically. When it fits, they disappear and the image stays perfectly centered.
🔍 View
Smart Centering
Whichever axis fits entirely — horizontal or vertical — stays centered on screen. Only the axis that overflows uses a scrollbar. So a tall document on a wide monitor stays horizontally centered as you scroll up and down.
🔍 View
Opens Maximized
GhostStamp opens full-screen by default so the canvas gets as much room as possible. Drag the window smaller if you want, or resize the sidebar with the splitter.
🔍 View
Adjustable Sidebar
Drag the splitter between the sidebar and canvas to resize the toolbar panel. Useful if you ever add seals with longer names.
💾 Saving
Save as PNG
Exports the stamped document at full original resolution as a lossless PNG. Stamps are redrawn at native scale during export, so they're razor-sharp — no resampling artefacts.
💾 Saving
Save as PDF
Writes a single-page PDF containing the stamped document. The PDF is a real, standards-compliant container — opens cleanly in any reader. The page size matches the document's original dimensions.
💾 Saving
Default Filename
The save dialog suggests originalname_Stamped — for example, Invoice.pdf becomes Invoice_Stamped.png. Original files are never overwritten unless you explicitly choose the same path.
💾 Saving
PDF Image Format
Internally, the exported PDF embeds the document as a JPEG-compressed image to keep file sizes reasonable. If you need lossless PDF output, save as PNG instead — it's the same pixels without any compression.
📖 Workflow
Typical Stamping Session
  1. Click Load Document and pick your invoice, scan, or contract.
  2. Type your initials in the Reviewer Name field.
  3. Pick the correct process date.
  4. Select a seal from the list — the cursor becomes a crosshair.
  5. Click on the document to place the stamp. The ghost preview shows you exactly where it will land.
  6. Adjust Seal Size if you want a smaller or larger overlay for the next stamp.
  7. Click Pointer Mode (or enable auto-return) to safely navigate.
  8. Click 💾 Save Stamped File and choose PNG or PDF.
📖 Workflow
Multiple Stamps on One Document
You can place as many stamps as you need — mix seals, colours, and sizes freely. Every stamp is stored in history and rendered on export. Use Undo Last Stamp to peel back one at a time if you misplace one.
⌨️ Shortcuts
Mouse & Keyboard
  • Ctrl+Wheel — zoom in / out
  • Wheel (plain) — scroll vertically
  • Click — place the currently selected seal
  • Drag splitter — resize the sidebar
⚙️ Advanced
Icon File
GhostStamp loads stamp.ico from the folder next to the exe if it exists. If the file is missing, the app still runs — it just falls back to the default .NET application icon.
⚙️ Advanced
Fully Portable
GhostStamp stores nothing outside its own folder. No registry keys, no AppData clutter, no recent-files list. Copy the folder to a USB stick and it works on any Windows machine with the .NET Framework installed.
⚙️ Advanced
Offline & Private
The app never touches the network. Your documents stay on your machine — nothing is uploaded, tracked, or shared. Everything runs locally.
🔧 Hidden
Zoom-Invariant Stamps
Stamps are stored in the document's own pixel coordinates, not the canvas's. Zoom in, zoom out, resize the window — the stamps stay glued to the exact same spot on the document. What you see at any zoom is always what gets exported.

🔴 About GhostStamp PRO

GhostStamp PRO is a small document stamping utility built for the mundane but important task of marking paperwork. It loads a scan or PDF, lays one or more seals onto it — PAID, APPROVED, REVIEWED, SIGN HERE, and a dozen others — and exports a clean PNG or PDF. No cloud, no accounts, no subscription. Everything runs on your own machine, stamps are stored in image coordinates so they survive any zoom level, and the exported files are indistinguishable from what you see on the canvas. It's the sort of tool that costs you nothing and saves you the faff of dragging a stamp image around in an image editor. Free, and always will be. 🔴
